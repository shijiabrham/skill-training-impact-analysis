# Skill-training-impact-analysis
Five-year analysis of skill training and employability outcomes using Python, MySQL and Tableau.
The project assessed outcomes across training completion, placement, salary growth, employment retention and post-training survey outcomes. It also examined changes in beneficiaries' income, financial condition, confidence and ability to save through follow-up survey data.
The analysis included data cleaning, exploratory data analysis and outcome assessment. An interactive Tableau dashboard was developed to present programme findings through data visualisation.”
## Objective
To assess employment and socio-economic outcomes associated with a skill training programme over a five-year period and examine patterns in placement, employment continuity, salary progression and post-training beneficiary outcomes.
## Methodology 
- Data cleaning and preparation using Python
- Exploratory analysis of beneficiary and programme outcomes
- SQL-based analysis of placement, employment retention and salary outcomes
- Cohort-wise analysis across financial years
- Outcome analysis using follow-up survey data
- Dashboard development and visualisation using Tableau
## Analysis Areas
- Training and placement outcomes
- Employment continuity and retention
- Salary progression and employment mobility
- Household socio-economic outcomes
- Financial condition and savings behaviour
- Beneficiary confidence and future earning expectations
- Integrated outcome analysis across programme and survey data
- Gender and workforce participation patterns
### Data Note
The original beneficiary-level data is confidential and is not included in this repository. Any data used in the publicly shared files has been masked, anonymised or replaced with dummy data for portfolio purposes.
